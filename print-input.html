🐍 Тренажёр: print и input

Функция print()

print() — функция, которая выводит информацию на экран (в консоль).

print("Привет, мир!")

Вывод: Привет, мир!

Вывод нескольких значений

print("Имя:", "Анна")
print("Возраст:", "20")

Между значениями автоматически ставится пробел.

Параметры sep и end

print("a", "b", "c", sep="-")   # a-b-c
print("Привет", end="!")
print("Мир")                 # Привет!Мир

Функция input()

input() — считывает строку, введённую пользователем. Всегда возвращает строку.

name = input("Введите имя: ")
print("Привет,", name)

Преобразование типов

Чтобы работать с числами, нужно преобразовать строку:

age = int(input("Сколько вам лет? "))
print("Через 5 лет вам будет", age + 5)

Используйте int() для целых чисел и float() для дробных.

Форматирование строк (f-strings)

name = "Аня"
age = "20"
print(f"Меня зовут {name}, мне {age} лет")
