Основные типы данных

В Python каждое значение имеет тип. Узнать тип можно с помощью функции type().

print(type(42))        # <class 'int'>
print(type(3.14))      # <class 'float'>
print(type("Привет"))  # <class 'str'>

🔢 int — целые числа

a = 10
b = -5
c = 0

💧 float — дробные числа

x = 3.14
y = -0.5
z = 2.0   # даже с нулевой дробной частью — это float
⚠️ Важно: результат деления / всегда float!
10 / 2 → 5.0 (float). Целочисленное деление // → int.

📝 str — строки

s1 = "Hello"
s2 = 'World'
s3 = "123"   # это строка, а не число!

Приведение типов

int("42")       # 42
int(3.9)        # 3  (отбрасывает дробь!)
float("3.14")   # 3.14
float(5)        # 5.0
str(100)        # "100"
str(3.14)       # "3.14"
⚠️ int("3.14") — ❌ ValueError!
Правильно: int(float("3.14")) → 3

Операции и типы

5 + 3       # 8    (int + int → int)
5 + 3.0     # 8.0  (int + float → float)
"5" + "3"    # "53" (str + str → конкатенация)
"Ha" * 3     # "HaHaHa" (str * int)
