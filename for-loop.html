🔄 Тренажёр: Цикл for в Python

💡 Главная идея: Цикл for в Python перебирает элементы последовательности. Это может быть строка, список, диапазон range, словарь — неважно! Цикл просто берёт каждый элемент по очереди.

Цикл for с range()

Функция range() создаёт последовательность чисел.

range(стоп) — от 0 до стоп-1

for i in range(5):
    print(i)
# Вывод: 0 1 2 3 4

range(старт, стоп) — от старт до стоп-1

for i in range(2, 6):
    print(i)
# Вывод: 2 3 4 5

range(старт, стоп, шаг) — с шагом

for i in range(0, 10, 2):
    print(i)
# Вывод: 0 2 4 6 8

for i in range(10, 0, -2):
    print(i)
# Вывод: 10 8 6 4 2 (обратный порядок)

Цикл for со строками

Строка — это последовательность символов. Цикл перебирает каждый символ.

text = "Python"
for char in text:
    print(char)
# Вывод: P y t h o n (каждый на новой строке)

Перебор с индексом

text = "Hello"
for i in range(len(text)):
    print(i, text[i])
# Вывод: 0 H / 1 e / 2 l / 3 l / 4 o

Цикл for со списками

Список — последовательность элементов. Цикл перебирает каждый элемент.

fruits = ["яблоко", "банан", "вишня"]
for fruit in fruits:
    print(fruit)
# Вывод: яблоко / банан / вишня

Перебор с индексом

numbers = [10, 20, 30]
for i in range(len(numbers)):
    print(i, numbers[i])
# Вывод: 0 10 / 1 20 / 2 30

Функция enumerate() — индексы + значения

colors = ["красный", "зелёный", "синий"]
for i, color in enumerate(colors):
    print(i, color)
# Вывод: 0 красный / 1 зелёный / 2 синий

Цикл for со словарями

Словарь — последовательность пар ключ-значение. По умолчанию перебираются ключи.

Перебор ключей (по умолчанию)

person = {"имя": "Анна", "возраст": 25, "город": "Москва"}
for key in person:
    print(key)
# Вывод: имя / возраст / город

Перебор значений

for value in person.values():
    print(value)
# Вывод: Анна / 25 / Москва

Перебор пар ключ-значение

for key, value in person.items():
    print(key, ":", value)
# Вывод: имя : Анна / возраст : 25 / город : Москва

Другие полезные конструкции

Функция zip() — параллельный перебор

names = ["Аня", "Боря", "Вика"]
ages = [20, 25, 30]
for name, age in zip(names, ages):
    print(name, "—", age)
# Вывод: Аня — 20 / Боря — 25 / Вика — 30

Вложенные циклы

for i in range(3):
    for j in range(2):
        print(i, j)
# Вывод: 0 0 / 0 1 / 1 0 / 1 1 / 2 0 / 2 1

Накопление суммы

total = 0
for num in range(1, 6):
    total += num
print(total)
# Вывод: 15 (1+2+3+4+5)
